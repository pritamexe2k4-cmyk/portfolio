# Preetam — Portfolio

Personal portfolio site and project notes.

**Stack:** Vite · React · TypeScript · Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Run `npm run build` for a production build. Portfolio content is maintained in [`src/data/site.ts`](src/data/site.ts).

The Harry Potter chatbot is listed under the existing customer-support project route and links to [harry_potter_project](https://github.com/pritamexe2k4-cmyk/harry_potter_project). Resume files and download links have been removed from the current repository.
