# Preetam — Portfolio

Personal portfolio site and project notes.

**Stack:** Vite · React · TypeScript · Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Run `npm run build` for a production build. Portfolio content is maintained in [`src/data/site.ts`](src/data/site.ts).

The four featured projects are NeuroFuse, DoctorGemma, Harry Potter Chatbot and IncluHub Dashboard. Project descriptions preserve team and upstream attribution and distinguish training loss from held-out evaluation.

The [current resume](public/Preetam_Naik_Resume.pdf) is the only published resume version. Its source is in `resume/build_resume.py`; older resume copies remain removed. The Contact page links to this PDF. Personal programming skills are Python and SQL; technologies used by a project are not automatically claimed as personal skills.

Recurring profile updates follow [the sync policy](profile/SYNC_POLICY.md).
