# Preetam — Portfolio

Personal portfolio site and résumé source.

**Stack:** Vite · React · TypeScript · Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Run `npm run build` for a production build. Portfolio content is maintained in [`src/data/site.ts`](src/data/site.ts); the résumé source is in [`resume/`](resume/).
